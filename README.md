# LastCamp
Опис проєкту

Last Camp — це 2D гра жанру survival management, розроблена на Unity 6. У грі гравець керує групою тих, хто вижив після глобальної катастрофи, збирає ресурси, створює предмети та намагається протриматися протягом 10 днів.

Основні можливості

Управління групою виживших:
Hunter (мисливець)
Engineer (інженер)
Medic (медик)

Система ресурсів:
Food
Wood
Metal

Система виживання:
Здоров'я (HP)
Рівень голоду (Hunger)

Збір ресурсів:
Search Food
Gather Wood
Gather Metal

Система харчування:
Feed Survivor

Система відпочинку:
Rest

Система ремесел:
Craft Axe
Craft Medkit
Build Campfire

Умови перемоги та поразки:
Перемога після виживання протягом 10 днів
Поразка у разі загибелі всіх персонажів

Ігрова механіка
Кожен персонаж може виконати лише одну дію протягом дня. Після завершення всіх дій гравець натискає кнопку End Day.
Наприкінці дня персонажі втрачають здоров'я та рівень ситості. Для виживання необхідно своєчасно добувати їжу, збирати ресурси та використовувати систему крафту.
